# Wheather-Analysis

# 🌦️ Weather Data Analysis

## 📌 Project Description

This project performs Exploratory Data Analysis (EDA) on a weather dataset using Python. It cleans the data, handles missing values, calculates average temperature, and visualizes different weather patterns using various charts.

---

## 🚀 Features

* Read weather dataset using Pandas
* Convert `Date.Full` column into datetime format
* Handle missing values
* Create Month and Day columns
* Calculate Average Temperature
* Daily Average Temperature Line Chart
* Correlation Heatmap
* Temperature Distribution Histogram
* Monthly Records Count Plot
* Temperature Distribution by Month (Box Plot)
* Rainfall vs Temperature (Scatter Plot)
* Wind Speed Distribution Histogram
